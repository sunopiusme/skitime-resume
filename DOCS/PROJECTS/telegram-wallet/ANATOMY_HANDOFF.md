# Handoff: разбор компонентов на странице кейса Wallet

## Что это

Пакет для переноса разборов компонентов в `skitime-resume`, на маршрут `/projects/telegram-wallet`.
Файлы `.dc.html` в этой папке — **дизайн-референс**, а не код для копирования. В них
показано, как должны выглядеть и вести себя блоки. Реализация идёт в существующем
окружении проекта: `Next.js App Router`, `CSS Modules`, локальный content layer, без новых
зависимостей.

## Точность

Высокая. Все значения ниже финальные, брать их 1:1. Шрифт тот же, `var(--font-sans)`
(InterVariable из `public/fonts`), палитра кейса из `globals.css`, палитра телефона
локальная (`--w-*`) внутри `WalletHome.module.css`.

## Порядок применения

Правки разбиты на четыре части. Первые две дают видимый результат сразу и не требуют
нового кода, третья добавляет разборы, четвёртая печатную спецификацию.

## 1. Полировка контраста в живом экране

Файл: `src/features/projects/telegram-wallet/live/wallet-home/WalletHome.module.css`

### 1.1 Тихие чернила светлой темы

В `.root`:

```
--w-ink-subtle: #6e6e73;   /* было #8e8e92 */
```

Причина: `#8e8e92` на белом даёт около 3:1. Это ниже порога для 13px, и суммы, счётчики
и подписи закрытых разделов читались вяло. `#6e6e73` даёт 4.8:1 при той же роли тихого
уровня. Тёмная тема остаётся на `#9a9ea6`.

### 1.2 Шевроны

`.foldChevron` и `.rowChevron`:

```
color: #a6a6ad;   /* было #c2c2c8 */
```

### 1.3 Переключатель в TON Space

Здесь был главный провал: подложка `#4a4e58` на треке `#2c2f37` отличалась слишком мало,
и `Main Wallet` с `TON Space` не различались на мониторах с низкой гаммой.

```
.screen[data-mode="ton"] .switch {
  background: #2f323b;            /* было #2c2f37 */
}

.screen[data-mode="ton"] .switchThumb {
  background: #ffffff;            /* было #4a4e58 */
  box-shadow:
    0 2px 6px rgba(0, 0, 0, 0.45),
    0 0 0 0.5px rgba(0, 0, 0, 0.35);
}

/* Активная опция на белой подложке обязана быть тёмной.
   Базовое правило берёт var(--w-ink), а в TON это #ffffff,
   поэтому нужен явный перебив. */
.screen[data-mode="ton"] .switchOption[aria-selected="true"] {
  color: #101216;
}

.screen[data-mode="ton"] .switchOption {
  color: #a8acb5;
}
```

Белая подложка не случайна: она перекликается с белыми кружками быстрых действий,
белым аватаром профиля и белым листом списка справа. Это уже принятый в TON Space приём,
переключатель просто входит в ту же семью.

## 2. Blueprint-стенд: острые углы и выключение сетки под текстом

Файл: `src/features/projects/telegram-wallet/blueprint/BlueprintStage.module.css`

### 2.1 Углы

```
.stage {
  border-radius: 0;   /* было 32px */
}
```

Реальный чертёжный лист не бывает со скруглением. На прямых углах карточка Wallet с её
радиусом 44px читается предметом, лежащим на бумаге, а не второй веб-карточкой.

### 2.2 Подложка бумаги под подписями

Цифры линеек и выноски пересекались линиями сетки. Добавить фон бумаги, чтобы сетка под
текстом выключалась:

```
.labelX,
.labelY {
  background: #e9edf3;   /* тот же цвет, что background-color у .stage */
  padding: 0 3px;
}

.dim {
  background: #e9edf3;
}
```

Штрихи и границы сегментов остаются на месте, читается как настоящая размерная линия.
Лучше вынести `#e9edf3` в токен `--blueprint-paper` в `.stage` и ссылаться на него в трёх
местах, чтобы цвет бумаги задавался один раз.

## 3. Разборы компонентов в кейсе

### 3.1 Где размещать

Файл: `src/content/projects/telegram-wallet/case.tsx`

Разборы идут вслед за своей текстовой секцией, внутри того же `<section className={caseStyles.part}>`,
после `<div className={caseStyles.column}>` с прозой, в `<div className={caseStyles.wide}>`:

| Секция кейса        | Разборы после неё                                  |
| ------------------- | -------------------------------------------------- |
| Навигация           | 01 Быстрое действие, 02 Служебные кнопки           |
| Wallet и TON Space  | 03 Переключатель, 04 Баланс                        |
| Активы и промо      | 05 Строка списка, 06 Промо, 07 Токены              |
| Экран целиком       | финальный `BlueprintStage` с `WalletHome`          |

Существующие правила `case.module.css` уже дают нужный ритм: `.part > .column + .wide`
поджимает чертёж к вводящему абзацу на 8–16px, а `.part > .wide + .column` даёт разрыв
12–20px перед следующей мыслью. Ничего добавлять не нужно.

### 3.2 Формат заголовков и подписей

Взят из `src/features/projects/composer/parts/InlineFigure.tsx`, чтобы кейс говорил одним
голосом. Никаких mono-кикеров над чертежами: у Composer лейбл фигуры опущен
(`frame="plain"`), заголовок один на блок.

- **Заголовок разбора**: `h3`, 20px, вес 680, трекинг −0.02em, интерлиньяж 1.3, цвет
  `--composer-ink`. Формула из двух частей через точку, как «До запуска. Контракт»
  у Composer: «Быстрое действие. Send и Deposit», «Служебные кнопки. Настройки и QR»,
  «Переключатель. Main Wallet и TON Space», «Баланс. Три ступени кегля», «Строка списка.
  Один паттерн на три раздела», «Промо. Wallet Earn», «Токены. Палитра, радиусы и модуль».
- **Сноска под чертежом**: ровно `InlineFigure.caption` — 15px, вес 400, трекинг −0.01em,
  интерлиньяж 24px, цвет `--composer-ink-subtle`, `max-width: 62ch`, по центру,
  `text-wrap: pretty`. Проще всего обернуть чертёж в `<InlineFigure frame="plain" caption="…">`
  и не писать свой класс.
- **Спека и обоснование**: под сноской, в `caseStyles.column` (мера 640). Спека
  `dl` в две колонки, подпись 14px вес 500 цвет `--composer-ink-subtle`, значение 14px
  вес 600 цвет `--composer-ink`, разделитель `1px solid --composer-hairline`.
  Обоснование обычной `caseStyles.prose`.

### 3.3 Правила письма

Это обязательная часть, а не стилистика: в тексте разборов **нет длинного тире**
и **нет служебных символов** `·`, `⇄`, `→`, `≥`, `≈`, `−`, en dash. Связки строятся на
двоеточиях, запятых и союзах, как в кейсе Composer. Вместо англицизмов через дефис:
«зона нажатия» вместо «тап-таргет», «подложка» вместо «thumb», «наведение» вместо hover,
«фокус клавиатуры» вместо focus-visible, «кнопка действия» вместо CTA, «интерлиньяж»
вместо lh, «адрес в блокчейне» вместо «блокчейн-идентичность». Английский интерфейс самого
Wallet не трогаем: `Send`, `Deposit`, `Total balance`, суммы остаются как в макете.

### 3.4 Общий компонент листа

Предлагаемое место: `src/features/projects/telegram-wallet/anatomy/AnatomySheet.tsx`
плюс `AnatomySheet.module.css`.

```
type Props = {
  title: string;
  caption: string;
  spec: Array<{ label: string; value: string }>;
  children: ReactNode;   // сам образец
  dims?: Array<{ size: number; label?: string }>;
  grid?: boolean;        // false для листа токенов
};
```

Лист: фон `#e9edf3`, `box-shadow: inset 0 0 0 1px rgba(15,23,42,.14)`, `border-radius: 0`,
паддинг `clamp(24px, 3.6vw, 48px) clamp(16px, 3vw, 48px)`, содержимое по центру.
Внутри плита `width: fit-content; padding: 48px` с сеткой 8 и 48 такой же, как
у `.gridLayer` в `BlueprintStage.module.css`. Паддинг 48 ставит образец на крупную линию.

Выноски: строка `display: flex` из сегментов фиксированной ширины,
`border-left: 1px solid rgba(15,23,42,.72)`, у последнего ещё `border-right`,
подпись 10px `font-variant-numeric: tabular-nums`, фон бумаги (см. 2.2).

### 3.5 Значения по разборам

Все числа уже есть в `WalletHome.module.css`, дублирую для спека-таблиц.

**01. Быстрое действие.** Значок 52 × 52, радиус 22 (0.42 от стороны), глиф 26 при штрихе
1.7–2.2, подпись 500 кегля 14 с интерлиньяжем 20 и трекингом +0.1, отступ значка от
подписи 8, зона нажатия 72 × 88, отклик подложкой `rgba(0,0,0,.05)`, ряд 312 = 4 × 72 + 3 × 8.
Под рядом отдельная полоса состояний с подписями «покой», «наведение», «фокус клавиатуры»:
состояния показываем копиями рядом, а не подкрашиваем кнопки в самом ряду, иначе ряд
читается как ошибка вёрстки.

**02. Служебные кнопки.** Круг 40 × 40, радиус 999, глиф 22 при штрихе 1.6, фон `#e5e2e9`
и `#dcd8e1` при наведении, в тёмной сцене `#2c2f37` и `#3a3d46`, шаг в строке 8.

**03. Переключатель.** Капсула 248 × 40, паддинг трека 3, подложка `calc(50% - 3px)` со
сдвигом на половину, подпись 600 кегля 14 с интерлиньяжем 18 и трекингом −0.1,
темп 180ms `cubic-bezier(.32,.72,0,1)`. Показывать три состояния: светлое A, светлое B,
тёмное.

**04. Баланс.** Знак валюты 30 тихим цветом, доллары 50 чернилами, центы 28 тихим,
вес 700, трекинг −1, интерлиньяж 54, `font-variant-numeric: tabular-nums`.
Подпись «Total balance» 600 кегля 18 с интерлиньяжем 20 и трекингом −0.3.
Слот `minmax(112px, 1fr)`, ширина секции 304.
Рядом профиль TON: аватар 56, подпись 500 кегля 14 с интерлиньяжем 18, адрес 700 кегля 30
с интерлиньяжем 36 и трекингом −0.4.
**Важно:** светлый баланс кладём на белую плашку (304 ширина, паддинг `16px 0`, радиус 16,
`inset 0 0 0 1px rgba(15,23,42,.12)`), иначе он лежит прямо на чертёжной бумаге, а тёмный
профиль рядом стоит на своей плашке, и пара читается асимметрично.

**05. Строка списка.** Высота не ниже 56, паддинг `8px 10px`, радиус 14, жетон 40 радиусом
999, имя 600 кегля 15 с интерлиньяжем 20 и трекингом −0.2, сумма 500 кегля 13 с
интерлиньяжем 17, разделитель 1px `rgba(0,0,0,.07)` с отступом 62 слева и 10 справа,
хвост списка отбит на 8 и его разделитель идёт от 10.
Заголовок раздела складки не ниже 48, 600 кегля 15, открыт ровно один раздел, он забирает
свободную высоту через `flex: 1`.

**06. Промо.** Плашка 304 × 76, радиус 20, бейдж 48 радиусом 20, оффер 600 кегля 16 и
500 кегля 13, кнопка действия высотой 32 радиусом 999 на `#17181c`, контраст текста около
12 к 1 по светлоте. Четыре радиальных свечения по углам плюс линейный низ, центр гасится
белым радиальным светом в `::after`.

**07. Токены.** Малый шаг 8, крупный 48, карточка 720 × 480 равна 15 × 10 крупным клеткам,
разбор ширины 24, 304, 24, 344, 24, темп один на всё, 180ms.
**Сетки на этом листе нет.** Палитра судится по цвету, а линейки за чипами подмешивают в
них холодный тон и спорят с краями. Лист лежит ровной бумагой, а сетка остаётся одним
панелем под радиусами и под разбором ширины, где действительно измеряется геометрия.
Отсюда флаг `grid` в пропсах `AnatomySheet`.

Чипы палитры: ряд из шести по 104px с шагом 8, высота 48, радиус 8, у белого и у
`#ffffff` в тёмном ряду `inset 0 0 0 1px rgba(15,23,42,.18)`, иначе чип теряется на бумаге.
Светлый ряд: `#ffffff`, `#f4f4f6`, `#e5e2e9`, `#007afa`, `#000000`, `#6e6e73`.
Тёмный ряд: `#17181c`, `#24262c`, `#2c2f37`, `#4a4e58`, `#ffffff`, `#9a9ea6`.
Лестница радиусов: 14, 20, 22, 44, 999 на квадратах 64.

## 4. Печатная спецификация

Пять листов A4 в альбомной ориентации, только компоненты, размеры и отметки, без описаний.
Описания живут на веб-странице.

- Лист 1: экран целиком с линейками, 720 × 480.
- Лист 2: кнопки, быстрое действие 52 / 22 и круглая 40 / 999.
- Лист 3: переключатель 248 × 40 и слот фокуса 304.
- Лист 4: строка списка 344 × 56 и складка разделов.
- Лист 5: промо 304 × 76, палитра и лестница радиусов.

Каждый лист: колонтитул сверху (название и штамп «ЛИСТ N ИЗ 5, МАСШТАБ 1 К 1, МОДУЛЬ 8 И 48»),
образец по центру, колонтитул снизу. Фон листа чертёжная бумага с сеткой, кроме зоны палитры.

Вариант реализации в Next.js: маршрут `src/app/projects/telegram-wallet/spec/page.tsx`
с `@page { size: A4 landscape; margin: 0 }` и `@media print`. В PRD уже заявлен
print-friendly `/resume`, так что для печатных страниц стоит завести общий модуль
и переиспользовать его здесь.
